The [self-hosted repository](https://github.com/lumyx-dev/self-hosted) runs the SFU behind
[Caddy](https://caddyserver.com), which gets a certificate for each domain.

```
                 ┌──────── Caddy :443 ────────┐
browser ──HTTPS──┤ SFU_DOMAIN /ws, /health → sfu:3000
                 └────────────────────────────┘
browser ──UDP 40000-40099──────────────────────► sfu (media)
```

## Requirements

- Docker with Compose v2.
- A DNS record for the SFU pointing at the server.
- Open ports: `80/tcp`, `443/tcp+udp`, and the media range (`40000-40099/udp` by default).

## Install

<CodeTabs
  tabs={[
    {
      label: 'bash',
      code: 'git clone https://github.com/lumyx-dev/self-hosted.git lumyx && cd lumyx\ncp .env.example .env   # set the domains and PUBLIC_IP\ndocker compose up -d',
    },
  ]}
/>

Clients connect their WebSocket to `wss://$SFU_DOMAIN/ws`.

## Settings

Everything is in `.env`:

| Variable | What it does |
|---|---|
| `SFU_DOMAIN` | Public hostname of the SFU. Caddy gets a certificate for it |
| `PUBLIC_IP` | IP advertised to browsers in ICE candidates. It must be reachable over UDP |
| `UDP_PORT_MIN` / `UDP_PORT_MAX` | Media port range, one port per connected peer: it caps concurrent participants |
| `SFU_VERSION` | Image tag, pinned to a release of sfu-core |
| `SFU_REGION`, `SFU_LOG` | Passed through to the SFU |

The SFU's `/metrics` endpoint is not exposed publicly: it stays on the Compose network.

## Upgrade

Bump `SFU_VERSION` in `.env`, then:

<CodeTabs tabs={[{ label: 'bash', code: 'docker compose pull && docker compose up -d' }]} />

## Without Docker

Behind your own reverse proxy, turn off in-process TLS and publish a UDP range:

<CodeTabs
  tabs={[
    {
      label: 'bash',
      code: 'SFU_TLS=false \\\nSFU_ICE_HOST=203.0.113.10 \\\nSFU_UDP_PORT_MIN=40000 SFU_UDP_PORT_MAX=40099 \\\nSFU_SERVE_TEST_CLIENT=false \\\ncargo run --release',
    },
  ]}
/>

Every variable is listed in [Configuration](/config).

## Known limits

<Aside type="caution" title="Before you deploy">
  - No STUN client: peers must reach `PUBLIC_IP` directly over UDP.
  - Images are `linux/amd64` only for now.
  - Telemetry persistence to Postgres is not wired into the Compose setup yet.
</Aside>
