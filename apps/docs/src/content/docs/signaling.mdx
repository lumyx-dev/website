Open one WebSocket per peer on `/ws`. Every message is a JSON object with a `type` field.

## A session

```
client                                  server
  │  ── ws connect /ws ──────────────────►│
  │  ◄──────────── connected {peer_id} ───│
  │  ── join {room_id} ──────────────────►│
  │  ◄──────── joined_room {peers[]} ─────│
  │  ── sfu_offer {sdp} ─────────────────►│
  │  ◄──────────── sfu_answer {sdp} ──────│
  │  ── sfu_ice_candidate ───────────────►│   ICE + DTLS
  │  ◄════════════ SRTP media ═══════════►│
```

## Client to server

| `type` | Payload | Purpose |
|---|---|---|
| `join` | `room_id`, `peer_id` | Enter a room |
| `sfu_offer` | `sdp` | Publish and subscribe offer to the SFU |
| `sfu_ice_candidate` | `candidate` | Trickle ICE toward the SFU |
| `leave` | none | Leave the room |
| `offer` / `answer` / `ice_candidate` | `sdp` / `candidate`, `target_peer_id` | Peer-to-peer relay path (mesh mode) |

## Server to client

| `type` | Payload |
|---|---|
| `connected` | `peer_id` assigned by the server |
| `joined_room` | `room_id`, `peers` already present |
| `peer_joined` / `peer_left` | `peer_id` |
| `sfu_answer` | `sdp` |
| `sfu_ice_candidate` | `candidate` |
| `error` | `message` |
