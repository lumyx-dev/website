You need [Rust](https://rustup.rs/) and [mkcert](https://github.com/FiloSottile/mkcert). The SFU serves
HTTPS because browsers refuse camera access and WebRTC on plain HTTP.

## Run it locally

<Steps>

1. **Clone the repository**

   <CodeTabs tabs={[{ label: 'bash', code: 'git clone https://github.com/lumyx-dev/sfu-core && cd sfu-core' }]} />

2. **Create a local certificate**

   The server reads `localhost+1.pem` and `localhost+1-key.pem` at the repository root. They are not
   versioned: each developer generates their own.

   <CodeTabs tabs={[{ label: 'bash', code: 'mkcert -install && mkcert localhost 127.0.0.1' }]} />

3. **Start the SFU**

   <CodeTabs tabs={[{ label: 'bash', code: 'cargo run --release\n# ✅ Serveur HTTPS sur https://localhost:3000' }]} />

4. **Open two tabs**

   Go to `https://localhost:3000` in two tabs and allow the camera in both. The server ships a test client
   on `/`: each tab shows the other's video, forwarded through the SFU.

</Steps>

<Aside type="caution" title="No STUN client yet">
  Peers must reach the advertised host directly: the same network, or a public IP set with
  `SFU_ICE_HOST`. See [Self-hosting](/self-hosting) before you put it on a server.
</Aside>

## Check it is running

The health route answers with the running version.

<CodeTabs
  tabs={[
    { label: 'request', code: 'curl -k https://localhost:3000/health' },
    { label: 'response', code: '{ "status": "ok", "version": "0.1.0" }', lang: 'json' },
  ]}
/>
